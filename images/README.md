# Image and video gallery

All publication media in this directory has been copied from the build archive,
resized where appropriate and stripped of EXIF metadata. The original files in
`screens/` remain untouched.

The collection is intentionally generous for the pre-publication review. Delete
any view that should not be public, then remove its link from this file and run
`python3 tools/update_checksums.py` followed by `python3 tools/verify_release.py`.
